# Ziheng Ma · 个人主页

深色 AI / 数学风格个人主页，为 **Ziheng Ma · 应用统计专业本科生** 制作。

## 直接部署到 GitHub Pages

不需要安装 Node.js，不需要构建，也不需要配置 GitHub Actions。

1. 解压文件，将本目录内的所有文件上传到 GitHub 仓库的**根目录**。确保根目录可以直接看到 `index.html`，而不是又套了一层文件夹。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**。
4. **Branch** 选择 `main`（或你实际使用的分支），目录选择 **`/ (root)`**，然后点击 **Save**。
5. 等待部署完成，访问 Pages 页面显示的网址。首次部署通常需要几分钟。

### 仓库如何命名？

- 想要主页地址是 `https://你的用户名.github.io/`：仓库名必须是 `你的用户名.github.io`。
- 使用其他仓库名（例如 `homepage`）也可以，网址通常是 `https://你的用户名.github.io/homepage/`。
- GitHub 用户名不是展示姓名：请替换成你真实的 GitHub 用户名，不要直接使用有空格的 `Ziheng Ma`。
- 建议使用公开仓库；私有仓库的 Pages 可用性取决于 GitHub 套餐。

> 所有本地资源采用相对路径，两种网址都能使用。若没有看到 `.nojekyll` 隐藏文件也没关系，本项目没有需要 Jekyll 处理的内容。

## 添加你的联系方式

打开 `script.js`，修改文件开头的内容：

```js
const PROFILE = {
  email: '你的真实邮箱',
  github: '你的GitHub用户名',
};
```

留空时不会显示邮箱或 GitHub 按钮，避免放入虚构的联系方式。已有“复制主页链接”按钮，在部署上线后可使用。

## 修改内容和配色

- `index.html`：名字、专业、自我介绍、探索方向、页面标题等。
- `styles.css`：配色、布局、移动端适配。顶部 `:root` 中的 `--purple`、`--mint`、`--lime` 是主要强调色。
- `script.js`：联系方式、网络动画和三个数学实验。
- `favicon.svg`：浏览器标签页的 `zm` 图标。

当前只使用你提供的姓名、专业和本科生身份，没有编造学校、成绩、项目或研究成果。“探索方向”为主题介绍；算法实验室明确标注为教学演示，回归数据是浏览器生成的模拟数据。你可以将学习介绍与探索方向改成更符合自己的文字。

## 页面内容

- 实时 3D 投影神经网络、旋转轨道和数学曲面网格。
- 代码卡片风格个人介绍。
- 统计推断、机器学习、数学建模主题卡片。
- 交互实验：梯度下降、正态分布、模拟数据线性回归。
- 移动端布局、键盘可操作的实验标签、减少动态效果支持。
- 页面切到后台或主视觉滚出屏幕时暂停相应动画，减少资源占用。

## 本地预览

可以直接双击 `index.html` 查看，复制链接功能需上线后使用。

如果安装了 Python 3，也可以在此目录运行：

```sh
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。

## 依赖和隐私

- 纯 HTML / CSS / JavaScript，没有框架、后端、追踪脚本或分析服务。
- Canvas 图形由本地代码绘制，不需要下载图片。
- CSS 第一行通过 Google Fonts 加载 DM Sans 和 Space Grotesk。无法连接时自动使用系统字体，内容和交互不受影响；想要完全无外部请求，删除该行即可。
- 修改后直接上传覆盖相应文件，GitHub Pages 会自动重新部署。
